# Student Tracking System (Система отслеживания успеваемости студентов)

MVP (минимально жизнеспособный продукт) веб-приложения для фиксации и анализа учебных результатов студентов. Проект разрабатывается в учебных целях с прицелом на соответствие коммерческим требованиям к вакансии Java Junior.

2. Согласование этапности разработки и кривых углов бэкенда.

## 🗄️ Структура данных (Проектируемые сущности)

### 1. Student (Студент)
* `id` (Long, Primary Key)
* `first_name` (String)
* `last_name` (String)
* `email` (String, Unique)
* `group_name` (String)

### 2. Subject (Учебный предмет)
* `id` (Long, Primary Key)
* `title` (String, Unique) — например: "Java Core", "Высшая математика"

### 3. Grade (Оценка)
* `id` (Long, Primary Key)
* `student_id` (ForeignKey -> Student)
* `subject_id` (ForeignKey -> Subject)
* `value` (Integer) — оценка от 1 до 5 (или баллы 1-100)
* `created_at` (LocalDateTime) — дата и время выставления

---

## 🛠️ Функциональные требования (Задачи для MVP)

### Слой REST API (Контроллеры):
* **Студенты:**
    * `POST /api/students` — создание нового студента.
    * `GET /api/students` — получение списка всех студентов с фильтрацией по группе.
* **Предметы:**
    * `POST /api/subjects` — добавление нового предмета в систему.
* **Успеваемость (Бизнес-логика):**
    * `POST /api/grades` — выставить оценку студенту по предмету (с валидацией: студент и предмет должны существовать).
    * `GET /api/students/{id}/average` — рассчитать средний балл конкретного студента по всем предметам.
    * `GET /api/subjects/{id}/top-students` — вывести топ-5 студентов с наивысшим средним баллом по данному предмету.
